# Royal Pizza - prototype de site vitrine

Prototype rapide pour présenter une vitrine web à Royal Pizza Clermont.

## Objectif commercial

Montrer au gérant une version concrète de ce que pourrait devenir son site:

- page d'accueil orientée appels et commandes;
- menu consultable sur mobile;
- adresse et téléphone visibles;
- SEO local autour de "Royal Pizza Clermont", "pizzeria Clermont" et "livraison pizza Clermont";
- base simple à déployer rapidement avec nom de domaine, hébergement et suivi.

## Structure

- `index.html` : accueil, présentation, appel, commande et contact.
- `menu.html` : carte consultable par catégorie.
- `styles.css` : design responsive.
- `script.js` : interactions légères.

## Aperçu local

Ouvrir `index.html` dans un navigateur, ou lancer:

```bash
cd c:\wamp64\www\royal_pizza
python -m http.server 8000
```

Puis ouvrir `http://localhost:8000/`.

## Données à confirmer avec le gérant

- horaires exacts;
- carte complète et tarifs à jour;
- zones de livraison;
- photos réelles de la pizzeria et des pizzas;
- préférence: appel direct, WhatsApp, formulaire ou vraie commande en ligne.
